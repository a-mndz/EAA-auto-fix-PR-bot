    How it works

    Four steps. A human stays in the loop.

    1. 1

      Scan

      Push to your default branch (or schedule it). A headless Playwright job runs axe-core across your configured URLs.

    2. 2

      Fix

      Deterministic fixes apply with zero LLM cost; semantic ones go to Claude and are scoped to detected rule IDs only.

    3. 3

      Review

      A PR opens with a before/after axe summary and a diff. The bot has no merge permission — you approve.

    4. 4

      Gate

      On merge, a re-scan runs as a check. Any regression vs. baseline fails the check and is flagged for review.
